dsh-prompt-crafter

输入框发送键旁的优化按钮：写完一段粗糙的草稿，按一下立即改写成更容易被大模型精准执行的高质量提示词。内置专属免费通道，不消耗对话额度，开箱即用。

核心特性与设计亮点

字面意义的完全免费

插件内置由作者维护的免费模型端点，所有安装者共用，无需填写任何 API Key，不消耗你的当前模型额度。设置页打开时自动发 Hi 进行端到端连通性测试。

智能性质判断（防过度扩写）

系统先做性质分类：确认、道谢、闲聊或简短提问保持原样精简；只有真正交付的任务才按档位加码。避免让「ok很好」被无意义扩写成一篇带背景和验收标准的论文。

三级弹性回退保障

若免费端点偶遇网络拥堵或超限，插件绝不会弹报错罢工，而是自动无缝切换至当前会话所用的模型通道继续执行改写，并在设置页记录回退明细。

深度会话路由探测

通过监听 agent/request 动态捕获当前会话的实际底层调用路由，解决普通插件在浏览器前端无法定位活跃模型绑定的痛点。

三档优化力度矩阵
档位 改写策略 适用场景
精简 只修复错别字、歧义与指代不清，几乎不改变原句长度与语序结构。 输入本身已较完整，仅需快速润色和去歧义。
均衡 (默认) 补齐模糊边界，明确输出格式与技术约束，长度适中，信息密度高。 绝大多数日常研发、编码与问答任务。
详细 将任务结构化拆解：补充背景意图、执行步骤、技术栈约束与验收准则。 复杂系统架构、长篇文档起草或关键代码重构。
进阶配置：使用自有专属端点

如果你有自己更高并发的私有模型端点，可直接在启动环境中覆盖：

DSH_FREE_CHANNEL_BASE_URL=https://your-endpoint/v1
DSH_FREE_CHANNEL_API_KEY=sk-...
DSH_FREE_CHANNEL_MODEL=your-model
安装与启用

在 DeepSeek Harness 桌面端打开「设置 ➔ 内置插件」，粘贴包名点击安装并重启：
