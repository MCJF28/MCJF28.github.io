dsh-visual-card

可视化回答插件：AI 提交一段 HTML，在对话流下方渲染成一个可交互、能点、能键盘操作、能全屏导出的生动卡片窗口。无论是复杂图表、交互表单还是纯 Canvas 像素小游戏均可直接流畅运行。

在线沙盒体验 安装说明
在线窗口交互效果体验
系统资源性能监控 (实时) 键盘已接管 · 按 ESC 释放

💡 提示：点击窗口内部即可激活焦点（小游戏模式下点击将接管键盘方向键，按 ESC 或点击外部可随时释放焦点）。

核心特性与架构设计

Iframe 独立事件域与键盘接管

AI 生成的脚本通常监听 document 的键盘事件。通过 Iframe 隔离事件作用域，只有点进窗口才接管键盘，窗口外部按键依然安全正常流向输入框。

内容驱动的自适应高度 (Auto-Height)

无需套死固定宽高比。宽度固定后，内容有多高卡片就多高。当超过设定的视口比例上限（默认 80%）时自动转为内部平滑滚动，绝不逼你滚动整个对话翻页。

原生深浅色主题 CSS 变量解耦

提供标准化变量支持：--v-bg-base、--v-border、--v-text、--v-brand，模型生成的 HTML 自动随应用深浅模式无缝切换。

本地持久化（~/.dsh/visual/cards.json）

卡片内容按会话与轮次落盘持久化存储，重启应用历史卡片依然完好呈现，保留轮数与上限可在设置面板自由定制。

键盘事件接管规则
操作行为 触发响应 设计考量
点进窗口 窗口接管键盘，标题栏显示「键盘已交给窗口」。 保证方向键和小游戏操作不会误触发页面滚动或文本输入。
按 Esc 键 瞬间释放键盘所有权，焦点自动回退到输入框。 给用户随时退出的最高优先级快捷键保障。
点击窗口外部 自动平滑释放接管状态。 符合直觉的离开交互，零心智负担。
鼠标悬停/滚动 始终正常响应，无需先获取焦点。 浏览卡片内复杂图表数据无需额外点击。
AI 模型端调用的 Tool Schema
render_visual({
  title: '实时系统负载分析',
  html: '<div style="color:var(--v-text)">...</div>',
  height: undefined // 可选，推荐不填按内容自适应
})
