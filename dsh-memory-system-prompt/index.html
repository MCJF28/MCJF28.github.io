Step 1 · 主动持久化
AI 主动调用工具写库
在交谈中识别出用户的编码规范、环境版本或偏好时，模型主动调用 memory_save 存入 ~/.dsh/memory/。
Step 2 · 零成本常驻
索引轻量常驻 SystemPrompt
每轮仅注入「标题 + 一句话摘要」。模型时刻知晓存在哪些记忆，却不消耗几千 Token 的正文篇幅。
Step 3 · 按需读全文
精准检索细节上下文
当用户问及相关细节时，模型再调 memory_read 抓取对应条目的详细正文，实现极高信噪比。

记忆微型工具套件
工具函数 调用时机与行为
memory_save 保存或更新一条长效事实，同名 Slug 自动覆盖更新。
memory_read 按 Slug 标识读取对应记忆的完整正文内容。
memory_list 列出全部记忆清单（默认仅返回标题与一句话摘要索引）。
memory_delete 删除一条已过时或被废弃的记忆条目。
核心工程考量与踩坑规避

杜绝 agent.inject 造成的自问自答

记忆索引必须通过 systemPrompt.context 注入。若错误使用 agent.inject，会被排队为一条用户输入，导致模型在输出完后再自言自语追加一轮对话。

运行时解耦避免 Fiber 挂起

系统提示词部分不把 systemPrompt 硬编码在 inject 列表，而是在运行时通过 agent.ctx.get() 延迟提取，彻底杜绝服务未就绪导致插件静默挂起的缺陷。
